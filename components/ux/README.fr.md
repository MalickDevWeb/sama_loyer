# Composants UX

Ce dossier est destiné aux composants axés UX (flux d'onboarding, écrans vides, frontières d'erreur, skeletons de chargement).

## Conventions

- Chaque composant suit le modèle à 4 fichiers : `index.js`, `index.json`, `index.wxml`, `index.wxss`
- Préfixe : `app-ux-` (par exemple `<app-ux-empty-state>`)
