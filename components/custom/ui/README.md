# ATS UI components

UI components developed for African Tourism Solutions live here. Boilerplate components remain under `components/ui/`.

| Component | Role |
| --- | --- |
| `chip-group` | ATS destination/category filters |
| `custom-tab-bar` | ATS tab bar presentation used by the WeChat `custom-tab-bar/` entry point |
| `destination-card` | ATS destination card |
| `layout` | ATS page layout |
| `list-destination` | ATS destination lists and their presentation |
| `reservation-card` | ATS reservation card |
